# @cellarer/cli

The command-line interface for cellarer, a local-first manager for AI agent
skills, MCP servers, and rules.

The stable package line starts at `0.1.0`. Install the registry release with
`npm install --global @cellarer/cli` or run it with `npx @cellarer/cli`. The
installed executable is `cellarer`, so the first-run command is `cellarer init`.
Node.js `>=20.19` is required.

Registry publication is separate from the repository's local release gate; the
gate never publishes packages, creates release tags, or changes dist-tags.
